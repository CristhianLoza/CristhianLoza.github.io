# Portfolio de Cristhian Loza Martínez

Portfolio personal estático creado con HTML, CSS y JavaScript.

## Antes de publicar

Edita en `index.html`:

- LinkedIn
- GitHub
- Correo
- WhatsApp

También puedes ajustar los proyectos y experiencia para incluir información pública y no confidencial.

## Publicar en GitHub Pages

1. Crea un repositorio llamado `TU_USUARIO.github.io`.
2. Sube `index.html`, `styles.css` y `script.js`.
3. En GitHub entra a Settings > Pages.
4. Selecciona Deploy from a branch.
5. Selecciona la rama `main` y la carpeta `/root`.
6. Guarda y espera a que GitHub publique el sitio.

Tu web quedará disponible en:
`https://TU_USUARIO.github.io/`
